# Bouffalo Lab

Bouffalo Lab designs RISC-V wireless SoCs for IoT, with Wi-Fi, Bluetooth LE, Zigbee, and Thread connectivity.

## Get started

| Repository | Description |
|---|---|
| [bouffalo_sdk](https://github.com/bouffalolab/bouffalo_sdk) | IoT and MCU SDK for all Bouffalo Lab chips |
| [toolchain](https://github.com/bouffalolab/toolchain) | RISC-V GCC toolchain ([China mirror](https://gitee.com/bouffalolab/toolchain/releases/tag/latest)) |
| [bflb_flash_tools](https://github.com/bouffalolab/bflb_flash_tools) | Flash programming tools |
| [arduino-bouffalo](https://github.com/bouffalolab/arduino-bouffalo) | Arduino core for Bouffalo Lab chips |
| [bl_docs](https://github.com/bouffalolab/bl_docs) | Datasheets and reference manuals |
