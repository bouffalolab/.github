# bouffalolab/.github

Default community health files for repositories in the [bouffalolab](https://github.com/bouffalolab) organization.

GitHub uses these files for any repository that does not provide its own file of the same type:

| File | Purpose |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Community standards and how they are enforced |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to ask questions, report bugs, and submit pull requests |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Issue forms: bug report, feature request |
| [.github/DISCUSSION_TEMPLATE/](.github/DISCUSSION_TEMPLATE/) | Discussion category forms, matched to category slugs |
| [.github/pull_request_template.md](.github/pull_request_template.md) | Pull request template |
| [profile/README.md](profile/README.md) | Organization profile shown on https://github.com/bouffalolab |

A repository with its own `ISSUE_TEMPLATE` folder does not use any of the default issue templates.
